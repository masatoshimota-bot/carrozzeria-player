carrozzeria U2-PLUS 元の24本スペアナ版（DSP削除）

・赤い表示エリアの拡大前に戻したバージョンです（24本スペアナ）。
・3D、SURROUND、BASS XTは表示、操作、音声処理から削除しました。
・11バンドEQ、Google Drive連携と自動フォルダー読み込みは維持しています。

【公開方法】
1. ZIPを解凍し、index.html / faceplate.jpg / manifest.webmanifest / sw.js / icon-192.png / icon-512.png を、GitHub Pagesの既存リポジトリ直下で上書きしてください。
2. 公開後はブラウザを再読み込みしてください。旧画面が残る場合、ブラウザのキャッシュを消して再度開いてください。
3. OAuthクライアント、Google Cloudの設定は変更不要です。同じ公開URLなら保存済みのフォルダー設定を維持できます。

【注意】
Google Driveは通信が必要です。OAuth再ログインが求められる場合があります。
単体HTML版は画面とローカル音楽の確認用です。Google連携はHTTPS公開して利用してください。

PTY / INFO文字とアイコンの欠けを修正。carrozzeriaロゴ直下の横線を削除。その他の機能とGoogleドライブ保存設定は変更していません。
