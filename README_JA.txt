carrozzeria U2-PLUS 表示修正版 v4
===================================

【修正内容】
- U2-PLUSの旧式Androidブラウザで画面領域が消える可能性があるCSSを回避しました。
- カーオーディオ本体画像をHTML内に埋め込み、画像ファイルの置き忘れでも表示できるようにしました。
- 24本の音声連動スペクトラム、11バンドEQ、音楽再生、マイク入力モードは維持しました。
- 以前の曲データを参照する IndexedDB名はそのままです。
- GitHub Pagesで古い画面がキャッシュされる問題を軽減する更新方式にしました。

【単体版の使い方】
- standalone.html をChromeで開いてください。カーオーディオ外観画像はHTMLに内蔵されています。
- HTTPSではないfile://で開いた場合、音声再生はできますがマイク取得は制限される場合があります。

【GitHub Pages 公開】
- index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, faceplate.jpg をルートに置いて公開してください。
- index.htmlには外観画像が埋め込まれているので、faceplate.jpg はバックアップです。
- 以前のファイルが残っている場所へ同名で上書きして公開します。
- 公開後は https://[GitHubユーザー名].github.io/[リポジトリ名]/player-v4.html を開いてください。以前のキャッシュが残っていても新しいURLとして開けます。
- 旧表示が残る場合はキャッシュ削除またはブラウザで再読み込みしてください。
- 画面が小さい場合、Androidの画面回転を横向きにし、ブラウザの表示倍率を標準にしてください。

【YouTubeについて】
- このアプリはYouTubeアプリの内部音声を直接解析できません。
- マイク解析モードは車内で流れている音をマイクが拾える場合のみ反応します。
- YouTubeを前面にするとスペアナアプリは裏に隠れます。
- マイク権限はHTTPSの公開URLから許可する必要があります。
- 運転中に画面操作しないでください。

【U2-PLUSファームウェア】
- v2023 0307 EAU はファームウェア識別情報と考えられますが、Androidバージョンの数字ではありません。
- ブラウザアプリ名・Androidのバージョン番号が不明なので、実機での表示は未検証です。
